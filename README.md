# WebTrafficCAD

瀏覽器即可使用的交通標線繪圖與車輛軌跡模擬工具。不需安裝，資料只存在你自己的瀏覽器與匯出的檔案中。

## 快速開始

```bash
npm ci
npm run dev      # http://localhost:3000/WebTrafficCAD/
npm test         # 幾何、DXF、數量計算單元測試
npm run lint     # TypeScript 型別檢查
npm run build    # 產出 dist/（部署到 GitHub Pages）
```

第一次使用可按「載入範本」直接取得一個雙向各 2 車道的十字路口，再依需要修改。

## 介面風格

右上角「介面風格」可在四種版面間切換（選擇會記在瀏覽器，也可用網址參數 `?ui=` 直接開啟）：

| 風格 | 網址參數 | 特色 |
|---|---|---|
| 經典（舊版） | `?ui=classic` | 原本的版面 |
| A・簡潔 | `?ui=minimal` | 細窄工具列＋「更多工具」，檔案／檢視收進選單，屬性面板只在需要時出現 |
| B・直覺（預設） | `?ui=guided` | 工具附文字並依法規分類、工具搜尋（Ctrl+K）、右側分頁：屬性／圖層／數量 |
| C・美觀 | `?ui=polished` | 滿版畫布、浮動玻璃面板、底部工具 Dock |

四種風格共用相同的功能與資料，切換不會影響圖面。

## 主要功能

- **標線**：分向限制線、分向線、車道線、路面邊線、雙白實線、調撥車道線、穿越虛線、停止線、讓路線、行人穿越道線（枕木紋）、禁止臨時停車線（紅）、禁止停車線（黃）、網狀線、槽化線、機車停等區、機車待轉區、指向線、路面標字、停車格／停車區、自行車道、人行道
- **精確繪圖**：端點／中點／交點／最近點／網格鎖點，Shift 正交，屬性面板可直接輸入座標、線寬與虛線段長
- **編輯**：框選、複製（Ctrl+C）、貼上（Ctrl+V）、原地複製（Ctrl+D）、右鍵旋轉 90°、平行偏移複製
- **輸出**：PNG（白底列印或深色，可加圖框、比例尺、指北針）、DXF（AutoCAD R12，單位公尺，依標線分圖層與顏色，具線寬）、數量計算表 CSV
- **資料保存**：每次修改後自動暫存於瀏覽器，重新開啟可還原；專案可另存為 JSON
- **圖層**：依標線類型顯示／隱藏，隱藏的圖層不匯出
- **軌跡模擬**：設計車種（小客車 P、單體貨車 SU-9、市區公車、半聯結車 WB-12，另有機車參考值，可自訂含雙節拖車）的掃掠範圍、淨距與轉彎檢核，支援前進＋倒車多段操作，詳見下節

## 軌跡模擬

切換到上方「軌跡模擬」後依三個步驟操作（右側分頁 ① 車輛 ② 路徑 ③ 結果）：

1. **選車種**：車輛庫附數值出處（AASHTO 設計車輛，最大轉角由最小設計轉彎半徑反算）。勾選「套疊」可在同一路徑比較多個車種；修改任何尺寸會自動另存為自訂車種。CAD 端的「設計車種」（小型車／大型車／聯結車）也使用同一份車輛庫。
2. **畫路徑**（左側工具）：
   - **點選＋半徑**（建議）：依序點節點，轉角以指定半徑圓弧連接，可加回旋曲線緩和段；拖曳◆把手可直接改半徑。
   - **路口轉彎**（建議）：在進入、離開路口的車道上按下並往行駛方向拖曳，自動產生轉彎曲線，可調控制比例、外擺與延伸。
   - **鋼筆曲線**、**筆刷手繪**：自由造型與快速草擬。
3. **看結果**：掃掠範圍、淨距帶、輪跡與車體骨架即時完整顯示（播放只移動車體）。結果分頁列出最大轉角、前／後軸與外側前角／內側後輪迴轉半徑、內輪差、最大掃掠寬度、最小淨距與衝突位置（點擊定位），可匯出檢核表 CSV 或列印。DXF／PNG 匯出會一併輸出 `SIM-*` 圖層與圖例。

行駛設定：路徑可代表前軸或後軸中心；倒車以後軸沿路徑計算。多段操作（例如前進進場後倒車入位）在「路徑」分頁按「從終點接續前進／倒車」，後一段以前一段終點的車身與各節拖車方向為初始狀態，播放時會自動接續。自訂車種可加第二節拖車（雙節聯結車、拖桿式全拖車）。轉向模式「精確跟隨」檢查路徑本身是否可行（超過最大轉角的路段以紅色標示），「轉角受限」則模擬在轉角上限內實際可行的軌跡並回報偏離量。

淨距檢核：建築線、人行道為硬障礙（可設定槽化線視為實體島）；分向限制線、雙白線、路面邊線、紅黃實線與槽化線回報越線；停止線、行人穿越道與車道虛線不列入。本模擬為低速運動學（單軌模型），不考慮輪胎側滑。

## 程式架構

- `src/markings.ts`：標線規格表（線寬、虛線、間距）、圖層表與每種物件的幾何產生器。畫布、PNG、DXF 都使用這份幾何，確保三者一致。
- `src/renderPrimitives.ts`：將幾何畫到 Canvas（畫面／列印配色）。
- `src/dxf.ts`、`src/exportPng.ts`：匯出。
- `src/ui/`：介面風格、工具目錄與新版面板元件。
- `src/simulation/`：軌跡模擬。`vehicles.ts`（車輛庫）、`pathBuilder.ts`（路徑建構）、`kinematics.ts`（運動學）、`analysis.ts`（掃掠、指標、淨距）、`store.ts`（狀態、復原、結果快取）、`render.ts`／`SimulationLayer.tsx`（畫布覆蓋層）、`interaction.ts`（滑鼠操作）、`persist.ts`（存檔與舊版轉換）、`ui/`（面板）。核心皆為純函式、單位公尺。
- `tests/`：單元測試（`node:test`，以 `tsx` 執行）。

新增一種標線時，在 `markings.ts` 的 `getElementPrimitives` 加上幾何、在 `LAYERS` 與 `MARKING_NAMES` 登記，畫面與匯出就會同時支援。

標線預設尺寸依《道路交通標誌標線號誌設置規則》通行內容整理，條文可能修正，各縣市亦可能有補充規定。可調整的數值（線寬、虛線段長與間距、槽化斜紋間距與角度、路面標字字高等）都已開放在屬性面板。送審或施工前請以主管機關最新公告版本核對。
